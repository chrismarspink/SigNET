“라벨은 스스로 문서를 지키지 않는다 — 인장이 라벨을 보증하고, 관문이 검증하며, 원장이 기억한다. 조직 안에서는 티켓, 조직 사이에서는 여권. Signet.”
본 화면은 보여주기 전용 프로토타입입니다. 모든 해시(SHA-256)·서명(ECDSA P-256)·체인 검증은 브라우저 WebCrypto 실연산이며, 페이지를 새로고침하면 키와 서명이 새로 생성됩니다.
※ 화면이 동작하지 않는 환경에서는 파일이 있는 폴더에서 python -m http.server 실행 후 http://localhost:8000 으로 접속하세요.
